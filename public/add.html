IPA / COLLECTION添加到个人源

CONTRIBUTE TO YOUR SOURCE

粘贴地址.

输入公开 GitHub 项目 / Release 页面，或免登录 IPA 直链。检查后加入你的个人源。

支持 GitHub 仓库 / Releases / Release 页面，以及公开 .ipa 直链。

多个 IPA 命中时会停止添加，请写得更具体，例如 *arm64.ipa。

最后一步会跳到 GitHub。需要用仓库所有者账号登录，并在那里点一次“提交”。添加请求会以 GitHub Issue 形式公开；自动化只接受仓库所有者本人提交的请求。通过检查后更新仓库并重新发布。不要输入私有链接、密码或令牌。
关于登录态：本页是静态页面，存不了 GitHub 登录，也读不到 github.com 的登录状态——登录只保存在你浏览器的 GitHub Cookie 里。所以请用 Safari 打开本页（不要用 App 内置浏览器，它的登录态是独立的、关掉就没），并把源首页“添加到主屏幕”，以后都从主屏幕图标进：GitHub 在 Safari 里登录一次后会长期保持，未登录时也会在登录后自动跳回预填好的提交页。提交成功后回源首页，这里会显示最终的成功状态。
